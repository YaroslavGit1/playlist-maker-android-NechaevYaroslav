# Playlist Maker

Android-приложение для поиска треков и создания плейлистов.

## Возможности

**Поиск**

- Поиск треков через iTunes Search API по названию или исполнителю.
- Задержка перед отправкой запроса и индикатор загрузки.
- Обработка пустого результата, ошибок сети и ошибок сервера с возможностью повторить запрос.
- История поиска: до 10 запросов, без дублей, свежие сверху. Хранится в DataStore и переживает перезапуск приложения.

**Экран трека**

- Обложка, название и исполнитель.
- Строки «Длительность», «Альбом», «Год», «Жанр».
- Добавление трека в «Избранное» и в плейлист через нижнюю шторку.

**Избранное**

- Список избранных треков, который хранится в Room.
- Долгое нажатие на трек удаляет его из «Избранного».
- Состояние «Избранного» восстанавливается при повторном открытии экрана трека.

**Плейлисты**

- Создание плейлиста с названием, описанием и обложкой из галереи устройства.
- Список плейлистов и экран плейлиста со статистикой: суммарная длительность и количество треков.
- Добавление треков в плейлист с экрана трека.
- Долгое нажатие на трек в плейлисте удаляет его из этого плейлиста.
- Обложка сохраняется с постоянным разрешением на чтение и не пропадает после перезапуска приложения.

**Настройки**

- Переключение светлой и тёмной темы с сохранением выбора.
- Поделиться приложением, написать разработчикам, пользовательское соглашение.

## Стек

- Kotlin, Jetpack Compose (Material 3)
- Navigation Compose
- ViewModel, Kotlin Coroutines / Flow
- Koin — внедрение зависимостей
- Retrofit + Gson — работа с iTunes Search API
- Room + KSP — треки, плейлисты и связи между ними
- DataStore (Preferences) — настройки и история поиска
- Coil — загрузка изображений

## Архитектура

Проект разделён на слои `data`, `domain` и `ui`. UI не обращается к источникам данных напрямую:

```
UI → ViewModel → Repository → источник данных (Retrofit / Room / DataStore)
```

```
data        сетевой клиент и DTO, Room (entity, dao, database), DataStore,
            реализации репозиториев, DI-модули
domain      модели (Track, Playlist) и интерфейсы репозиториев
ui          экраны, навигация, переиспользуемые компоненты, тема, ViewModel
```

Зависимости связываются через Koin.

## Хранение данных

- **Room**, база `playlists_maker`: таблицы `tracks`, `playlists` и промежуточная `playlist_tracks`.
  Связь «многие ко многим» реализована через `playlist_tracks`, поэтому один трек может входить
  в несколько плейлистов.
- **DataStore**: выбранная тема приложения и история поиска.

## Требования

- Android Studio (актуальная стабильная версия)
- JDK 11
- Android SDK: `compileSdk` 37, `targetSdk` 37, `minSdk` 29

## Сборка и запуск

1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. Соберите debug-сборку:

   ```
   ./gradlew :app:assembleDebug
   ```

   На Windows:

   ```
   gradlew.bat :app:assembleDebug
   ```

3. Запустите приложение на устройстве или эмуляторе (Android 10+, API 29) кнопкой Run
   в Android Studio либо установите APK вручную:

   ```
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

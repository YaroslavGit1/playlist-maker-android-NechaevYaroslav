# Playlist Maker

Android-приложение для создания плейлистов и поиска треков.

## Возможности

- Главный экран с переходами в поиск, плейлисты, избранное и настройки.
- Поиск треков по названию или исполнителю с индикатором загрузки, обработкой
  пустого результата и ошибок.
- Экран деталей трека.
- Настройки: тёмная тема (сохраняется между запусками), поделиться приложением,
  написать разработчикам, пользовательское соглашение.

## Стек

- Kotlin, Jetpack Compose (Material 3)
- Navigation Compose
- ViewModel + Kotlin Coroutines / Flow
- Koin (внедрение зависимостей)
- DataStore (Preferences) для настроек
- Gson для передачи модели трека в навигации

Архитектура разделена на слои: `data`, `domain`, `ui`.

## Требования

- Android Studio (актуальная стабильная версия)
- JDK 11
- Android SDK: `compileSdk` 37, `targetSdk` 37, `minSdk` 29

## Сборка и запуск

1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. Соберите debug-сборку:

   ```
   ./gradlew :app:assembleDebug
   ```

   На Windows:

   ```
   gradlew.bat :app:assembleDebug
   ```

3. Запустите приложение на устройстве или эмуляторе (Android 10+, API 29)
   кнопкой Run в Android Studio либо установите APK вручную:

   ```
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

## Структура проекта

```
app/src/main/java/.../
├── data        # сетевой клиент, эмулятор хранилища, DTO, репозитории, настройки
├── domain      # модели и интерфейсы репозиториев
└── ui          # экраны, навигация, компоненты, тема, ViewModel
```
